# Mental Health & Burnout Risk Prediction

## Overview
This project uses Machine Learning techniques to predict mental health issues and burnout risk among employees based on workplace and personal factors. The goal is to help organizations identify employees at risk and support workplace well-being.

---

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Multiple Machine Learning models
- Model evaluation and comparison
- Burnout risk prediction
- Mental health classification

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## Machine Learning Models Used
- Logistic Regression
- Decision Tree
- Random Forest


---

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

---

## Dataset
The dataset contains workplace-related factors such as:
- Working hours
- Stress level
- Job satisfaction
- Work-life balance
- Mental fatigue score
- Company type
- Employee resource allocation

---

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Model Evaluation
7. Prediction & Results

---

## Results
The models were trained and evaluated to identify the most effective approach for burnout prediction. Random Forest and other ensemble models achieved strong performance on classification tasks.
